Install from URL

PyRun downloads the .zip (up to 50 MB) and installs or updates it exactly like an upload. Give its sha256 to be sure you get the file you expect.

{# Help (side panel on desktop, under the form on phones) #}

What happens next

  • The .zip is validated (path-traversal safe) and unpacked — its code is not imported.
  • A registry entry is created with status Installed.
  • Click Activate to validate it in an isolated process, then restart to load it.
  • A zip of an installed plugin with a higher version updates it in place: its settings, secrets and data stay, and the old version is kept for a rollback.
