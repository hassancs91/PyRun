How it works

The file is one JSON object: each key becomes an entry and its value is stored as is, e.g. {"plan": "pro", "limits": {"runs": 100}}. A file from Export JSON imports again unchanged.

It is an upsert: new keys are added, keys already in the store get the file's value, and keys the file doesn't name stay as they are. Nothing is deleted.

Preview counts what would change, and writes nothing. Import writes every change at once: if anything fails, nothing is written.
