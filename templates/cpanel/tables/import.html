How it works

CSV columns are matched to table columns by name, ignoring case, spaces, dashes and underscores (“E-Mail” fills email, “Lead Score” fills lead_score); id, created_at and updated_at are skipped, since every row gets new ones. When two CSV columns match one table column, or one matches two, nothing is guessed: choose under Columns once the file is picked. An empty cell is no value; a JSON column's cell is read as JSON.

The whole file is checked first. If any line fails, nothing is written and the first errors are listed with their line numbers. A file exported from this page imports again unchanged.
