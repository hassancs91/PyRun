WhatsApp setup

  • Create a Meta app (type Business) with the WhatsApp product; its API Setup page has a free test number.
  • Copy the Phone number ID and WhatsApp Business Account ID from API Setup.
  • Make a permanent token: Meta Business settings → System users → Generate token with whatsapp_business_messaging.
  • For inbound, add the app secret and a verify token of your choice, then turn Inbound on and paste the callback URL into the app's WhatsApp → Configuration.
  • Outside the 24-hour window only approved templates can be sent: set a default template with one {% templatetag openvariable %}1{% templatetag closevariable %} variable.

Full walkthrough: the Chat channels guide (docs/channels.md).
